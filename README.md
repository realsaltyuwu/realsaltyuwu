# Hello, I'm realsaltyuwu 👋

I write backend systems in Go and Python, mostly FastAPI glued to Postgres and Redis, shipped in Docker containers. Lately I keep coming back to the same questions — what makes a service boundary feel right, when does an abstraction start costing more than it saves, and why do I always underestimate the database layer. Distributed microservices pulled me in because they sit right at the edge where clean design meets messy reality.
